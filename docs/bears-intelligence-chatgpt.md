# Bears Intelligence — design comparison
Isolated route /chicago-sports/bears/lab. No existing files changed. Uses installed React, Next and Framer Motion; CSS container queries simulate component widths. All data is synthetic. The illustrated player is a generic uniform, with optional ESPN headshot, not an accurate full-body likeness. Idle motion is whole-figure movement. The territory chart uses depth categories, not tracking coordinates. Third-down benchmarks are fixtures. Experience, Components and Motion modes share presentation components. Components mode exposes simulated states; they are not real fetch states. Next steps: real data ingestion, ID mapping, licensed art, automated accessibility and browser tests. Run npm run lint, npx tsc --noEmit, npm run build, then npm run dev. No deployment intended.

## Real data experiment
The portfolio uses static export, so no server routes or credentials are needed. From the repository root run:
```sh
python3 scripts/build-bears-analytics.py 2025
npm run dev
```
Select nflverse and 2025 in the lab. Generate 2024 or 2026 separately if the release exists. Output is public/data/bears-intelligence/YEAR.json; commit it to the feature branch only after validation if you want the preview site to serve it. The generator downloads public nflverse play-by-play and roster releases; source: https://github.com/nflverse/nflverse-data (attribution: nflverse/nflfastR, CC BY 4.0; check upstream terms before publishing). The script uses regular-season plays, excludes no-play and two-point attempts, excludes sacks from pass attempts, computes standard NFL passer rating, and joins GSIS to ESPN IDs via roster data. League completion benchmarks are attempt-weighted by direction/depth; third-down benchmarks use recorded conversion/failure flags by distance. EPA per attempt uses only attempts with nonmissing EPA. Season league passer rating is a cumulative attempt-weighted-input calculation, not an average of weekly ratings. These definitions may differ from official totals and should be reconciled. The current roster picker remains a sample list and real rankings and non-passing player totals are not implemented; no sample ranking is shown in real-data mode. Missing zones currently suppress the entire territory chart. The generated JSON is not committed by this change; run the generator first. No automated refresh or deployment changes yet.

## Running back intelligence
Regenerate season JSON after pulling this revision. The generator aggregates Chicago rushing plays with a recorded rusher ID and rushing yards, excluding kneels, no-plays and two-point attempts. Seven classified lanes use run_location and run_gap (end, tackle, guard); middle is the middle location rather than an observed exact center gap. Unknown lanes contribute to totals but not the diagram. League YPC is calculated for all eligible rushers, not exclusively running backs. Success is positive EPA among carries with nonmissing EPA, and EPA per carry uses that same recorded subset. Explosive categories are 10–19 and 20+ yards. Weekly bars represent the magnitude of the selected metric, with negative values explicitly labeled and colored blue. No live receiving splits, RB rankings or red-zone splits in this revision. Validate generated statistics against official totals, particularly exclusions and missing fields, before publishing. Sample mode remains independent.
