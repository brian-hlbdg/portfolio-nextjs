# Spatial continuity prototype
Isolated /studio route. Fixed SVG composition, flat illustrative code, geometry and measurement guides. Explore button opens a spatial index; Escape returns. Desktop translates the introduction; mobile uses vertical flow. Practice is a provisional inline preview; Work, Journal and About link to existing routes. No new dependencies or production merge. Validate keyboard, focus, narrow widths, reduced motion, and build before promoting. Visual design and copy are exploratory. SVG is decorative, not an invisible navigation target. Root chrome override is scoped using :has(.studio).
