# Accessibility

Target WCAG 2.2 AA; no conformance claim before audit. Track #43.

Check keyboard navigation and dialog focus trap/return, visible focus, touch targets (aim 44 CSS px), text contrast, non-color chart cues, meaningful labels and status announcements, zoom/reflow, screen reader reading order, reduced motion, scrollable field region accessibility and text equivalents for charts. Test iPhone Safari/VoiceOver and desktop keyboard; record browser/version and issues. Avoid focus stealing during data updates. Automated checks supplement, not replace, manual evaluation.
