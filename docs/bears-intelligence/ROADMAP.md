2. Verify player navigation; enrich profile and artwork (#68, #70, #44).
3. Define shared editorial contracts and metric definitions (#80, #74); deliver player stories (#71).
4. Expand analytics and team/leadership content after source checks.
5. Backfill historical seasons incrementally; validate comparison semantics.
6. Evaluate forecasts against baselines; no production prediction until validated.

Documentation, accessibility and performance run throughout. Release 1.0 is the initial delivered experience, not a declaration of complete accuracy. Do not close an issue solely on merge.
